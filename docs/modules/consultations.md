# consultations

## Module overview

Provides a first-party consultation workspace shared by patient and doctor that tracks appointment state and records clinical outcomes.

> This page is generated from `openspec/specs/consultations/spec.md`. Regenerate with `pnpm docs:generate`.

## Requirements

- Join consultation workspace
- Track consultation state
- Record consultation notes and prescriptions
- No external conferencing required
